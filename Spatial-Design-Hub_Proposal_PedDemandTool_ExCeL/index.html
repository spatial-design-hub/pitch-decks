01 / The tool

See the day on a live site map.

ExCeL enters the events for a day and sees which routes, entrances and hall doors become crowded, and when, on a map coloured red, amber or green. Pick a sample day, drag the time slider or press play, and select any route for its chart. The sketch is schematic and not to scale, and every event and value in it is made up.

In Stage 2, ExCeL editors can add, close, remove and resize entrances, doors and routes, then re-run any day. Changes are saved as named options so the agreed baseline is never overwritten, any option can be compared with the baseline, and the tool checks that every hall can still be reached before a run.

02 / Relevant experience

A team that has built this kind of tool before.

The same team, technology and engine-first approach behind these tools would build ExCeL’s crowd planning tool.

Spatial Design Hub · In-house tool

Static Pedestrian Modelling Tool

Built to size pedestrian routes in stadiums, stations and masterplans. It turns drawn pedestrian networks and origin–destination demand into required route widths, Level of Service, and escalator and gateline requirements, across multiple scenarios.

Relevance: the ExCeL tool uses the same technology and the same engine-first approach, with the calculation engine proved against an existing spreadsheet before the screens are built.

Describes the tool’s capabilities; its results are calculated estimates from a static model, not micro-simulation.

Eastern City Cluster BID, working with Publica · Digital tool

Eastern City BID Construction Impacts Monitor

An interactive dashboard that tracks construction impacts across the district in one place. It shows every site’s start and end dates and which phases of work are underway, generates a report for each site, and calculates the bus routes, stops and workers affected in each impact zone.

Relevance: a map-led dashboard driven by dates and phases, with a report for each item, like the event calendar, time slider and day reports.

Describes the tool’s capabilities; affected routes, stops and worker numbers are calculated estimates.

With Momentum Transport Consultancy · Lead GIS and app developer

Micromobility Planner

An online tool that helps local authorities plan shared mobility schemes, evaluate operating areas and parking, and assess expansion options, combining public transport accessibility with Census 2021 data.

Relevance: Spatial Design Hub and Momentum turning a transport planning method into a web tool, as on this project.

Describes the tool’s published capabilities; no adoption, ridership or carbon outcomes are claimed.

Spatial Design Hub digital tool

Urban Access

A tool bringing public transport accessibility, population context and amenity access together for planning and site assessment, with neighbourhood analysis and summary reports.

Relevance: an interactive map with summary charts and reports, the same pattern as the ExCeL dashboard.

Describes the tool’s capabilities; no time or cost savings are claimed.
